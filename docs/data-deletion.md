# ORACLY Data Deletion

**Last updated: September 13, 2026**

ORACLY provides users with ways to delete account-related and personal data.

## Delete your ORACLY account in the app

1. Open **ORACLY**.
2. Open **Settings**.
3. Open **Privacy / My Data**.
4. Choose **Permanently delete account**.
5. Confirm the deletion request.

When the in-app deletion flow succeeds, ORACLY first performs an authenticated server-side deletion workflow for supported user-owned service data. This includes applicable reading and operation records, memory/personalization data, staged reading inputs and attributable stored objects, Gem/account state, and notification-token records associated with the current ORACLY identity.

After the server deletion workflow is accepted, ORACLY deletes the current Firebase authentication identity and clears user-bound data stored locally on the device, including applicable local history, favorites, memory/personalization data, cached account state, and local entitlement state.

Some limited purchase, fraud-prevention, accounting, security, dispute-handling, or audit records may need to be retained. Where feasible, those records are kept without active account ownership and in pseudonymous form so that purchase integrity and legitimate restore/recovery flows can continue without retaining ordinary user content.

## If you cannot access the app

If you can no longer access ORACLY, or if you need help with deletion, send an email to:

**ftylmz32@gmail.com**

Use the subject:

**ORACLY Data Deletion Request**

Please include enough non-sensitive information to help us locate the relevant ORACLY account or request. Do **not** send passwords, payment-card details, purchase tokens, API keys, authentication tokens, or other secrets.

We will use the information only to identify and process the deletion request or provide deletion assistance.

## Data that may be covered by deletion

Depending on your use of ORACLY, deletion may cover data such as:

- account/application identifiers associated with the active ORACLY identity;
- saved reading or operation records associated with the account;
- uploaded reading inputs that remain in ORACLY-managed storage;
- personalization or memory records associated with the account;
- Gem/account state and supported user-bound transaction metadata;
- notification/device-token records associated with the account;
- other user-bound service data that can reasonably be linked to the active account.

## Data stored only on your device

Some ORACLY data is stored locally on your device. You can clear supported categories from ORACLY's privacy controls, use **Permanently delete account**, or uninstall the application to remove remaining app-local data from that device.
