## Mission

ORACLY exists to create **moments of reflection**.

It does not promise certainty.  
It does not predict destiny.  
It creates **space for thought**.

We are not a fortune-telling machine. We are a quiet room where someone can sit with a question, draw a card, read what stirs in them, and return later to see who they were becoming.

---

## Our Belief

People do not return because an application is beautiful.

People return because of **how it makes them feel**.

Every screen, every transition, every interaction must protect that feeling.

Beauty is not the product. Beauty is what happens when nothing unnecessary stands between the user and themselves.

---

## Our Values

When values conflict, choose the left column.

| We choose | Over |
|-----------|------|
| **Calmness** | Excitement |
| **Meaning** | Decoration |
| **Clarity** | Complexity |
| **Presence** | Speed |
| **Craftsmanship** | Quantity |
| **Reflection** | Prediction |
| **Trust** | Manipulation |
| **Timelessness** | Trends |

A feature must serve at least one of these: **Calmness · Reflection · Curiosity · Personal growth · Beauty · Trust**.  
If it serves none, it does not exist.

---

## Design Philosophy

Nothing exists without purpose.  
Nothing moves without intention.  
Nothing shines without reason.

- Every pixel earns its place.
- Every animation supports emotion — never spectacle.
- Every shadow supports depth — never drama for its own sake.
- Every color supports meaning — never noise.

**Luxury is subtraction.** Confidence is simplicity. Silence is part of the interface.

We do not add layers to impress. We remove until what remains feels inevitable.

---

## Product Philosophy

Do not build features because competitors have them.  
Build features because users will **remember** them.

Every new capability must answer:

> **Why does ORACLY deserve to exist because of this?**

If no meaningful answer exists, do not build it.

### The spine

ORACLY is one ritual, deepened over time:

**Draw → Pause → Reflect → Return**

Tarot is the ceremony. The journal is the relationship. Everything else is optional until the spine is flawless and trusted.

### What we refuse

- Feature buffets that ask users to browse instead of breathe
- Gamified spirituality — streaks, levels, spiritual XP
- Atmosphere we cannot deliver — dead taps, fake data, mock commerce
- AI that speaks with authority over the user's inner life
- Beauty without integrity — craft in the frame, lies in the behavior

---

## User Experience

The user must always feel:

- **Safe** — nothing manipulates, nothing lies, nothing rushes them toward payment before value
- **Respected** — their words matter more than our metrics; their emptiness is honored, not filled with fiction
- **Calm** — one primary path, one voice, one emotional register
- **Curious** — rewarded attention, not punished with clutter

They must never feel:

- Manipulated  
- Rushed  
- Overwhelmed  

If a screen asks the user to *perform* spirituality instead of *practice* it, the screen has failed.

---

## Technical Philosophy

Prefer **maintainability** over cleverness.  
Prefer **consistency** over novelty.  
Prefer **systems** over exceptions.  
Prefer **reusable craftsmanship** over one-off effects.

One press language. One chamber background. One tile primitive. One chat architecture. One honest settings row.

Code that cannot be maintained with the same care as the reveal animation does not ship.

---

## Decision Gates

Before approving any change — feature, pixel, or line of copy — ask:

### 1. The feeling test
*Does this protect or dilute how the user feels in the ritual moment?*

### 2. The five-year test
*If this remained unchanged for the next five years, would we still be proud of it?*

If no → continue refining.

### 3. The disappearance test
*If this vanished today, would ORACLY become worse?*

- **No** → remove it  
- **Maybe** → simplify it  
- **Yes** → ensure it earns its place  

### 4. The honesty test
*Is this real? Does it work? Does it say what it means?*

Fake stats, dead buttons, settings that save but never apply, premium that activates without payment — these violate the manifesto regardless of how they look.

## Success

ORACLY should never strive to become the largest spiritual application.

It should strive to become **the most loved one**.

Not because it predicts the future.

Because it helps people spend a few meaningful minutes with themselves.

That is the purpose of ORACLY.
