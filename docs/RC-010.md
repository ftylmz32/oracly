---

## Mission

Transform individual sessions into meaningful long-term understanding by detecting only observable patterns — never predicting, inferring facts, or fabricating meaning.

---

## Inputs

Consumed via `IntelligenceLayerService` / `ReflectionSource`:

- Completed readings, spreads, cards drawn
- AI reflections (stored summaries)
- User journal entries, favorite cards
- Recurring keywords, timestamps
- Ritual history

---

## Output models

| Model | Purpose |
|-------|---------|
| `ReflectionSummary` | Top-level structured output |
| `RecurringTheme` | Themes, cards, journal topics that repeat |
| `GrowthInsight` | Observable focus shifts (uncertain language) |
| `JourneyMilestone` | Factual markers (first reading, recurring card, etc.) |
| `PersonalTrend` | Rising/steady/fading patterns across time windows |

---

## Architecture

```
IntelligenceLayerService
        │
        ▼
ReflectionEngineService ──► ReflectionEngine (pure logic)
        │                         │
        │                    Analyzers (theme, card, topic,
        │                              milestone, focus, trend)
        ▼
ReflectionSummary (future: Home, Reading, Chat, Journal)
```

**Rules:**
- Engine is UI-agnostic and AI-agnostic
- AI never writes to the engine — only stored history is analyzed
- `ReflectionSource` interface extends to Dream, Astrology, Numerology, Moon Rituals

---

## Analyzers

| Analyzer | Detects |
|----------|---------|
| `RecurringThemeAnalyzer` | Theme tags from reading history |
| `CardPatternAnalyzer` | Frequently appearing cards |
| `ReflectionTopicAnalyzer` | Repeated journal keywords |
| `EmotionalFocusAnalyzer` | Focus shifts between 45-day windows |
| `MilestoneAnalyzer` | First reading, favorites, recurring cards |
| `PersonalTrendAnalyzer` | Theme, card, spread, reflection cadence trends |
