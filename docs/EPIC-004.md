---

You are no longer building software.

You are **preserving a feeling**.

Every future decision must protect that feeling.

---

## Mission

ORACLY must become **emotionally recognizable**.

Not because of logos.  
Not because of colors.

Because of **consistency**.

The same peace. The same breath. The same respect. Every time.

---

## The soul

The user should always feel:

> **"I am entering the same sacred place."**

Whether they open:

| Chamber | Same soul means |
|---------|-----------------|
| **Home** | Threshold — calm invitation, not a dashboard |
| **Tarot** | Ritual — held breath, not slot machine |
| **Astrology · Dream · Numerology** | Same chamber, different doorway |
| **Journal** | Personal archive — quiet, honest, theirs |
| **Settings** | Respectful control — no false toggles |
| **Premium** | Depth offered, never access withheld dishonestly |

Everything belongs to **one sanctuary**.

If a screen feels like a different app, the soul is broken.

---

## Emotional check

Every implementation must answer **yes** to at least one — ideally several:

| Question | What it protects |
|----------|------------------|
| Does this increase **peace**? | Calmness over stimulation |
| Does this increase **trust**? | Honesty over spectacle |
| Does this increase **reflection**? | Inner life over metrics |
| Does this respect **silence**? | Space over noise |
| Does this respect the user's **intelligence**? | Dignity over manipulation |

If none apply — the work does not belong in ORACLY.

---

## No feature exists alone

Every new module must inherit the sanctuary inheritance stack:

| Layer | Canonical source |
|-------|------------------|
| **Motion** | `OraclySignatureMotion`, `OraclyPressable`, emotional rhythm tokens |
| **Light** | Chamber gradients, specular discipline, one ambient breath per screen |
| **Glass** | `OraclyCrystalFrame`, `GlassCard`, OR Lattice |
| **Typography** | `OraclyTypography`, engraved hierarchy, one voice |
| **Spacing** | `OraclyRhythm`, `AppSpacing`, gallery calm |
| **Timing** | Press 220ms / release 280ms — invisible, physical |
| **Emotional rhythm** | Peak at reveal · calm in reading · hold in journal |
| **Interaction philosophy** | Touch confidence · no dead affordances · haptic on commit |

**Nothing may create a second identity.**

A feature that needs its own background, its own press curve, or its own copy tone has not earned a place yet.

---

## Decision test

| Signal | Verdict |
|--------|---------|
| Exciting **only the first time** | **Reject** — spectacle, not soul |
| More valuable **after six months** | **Prioritize** — journal, insights, returning rituals |
| Stronger on **day one** than **day hundred** | **Suspect** — likely gamification or novelty |
| Felt on **return visit** without explanation | **Keep** — this is the soul |

The soul compounds. Novelty fades.

---

## The 10-year rule

Build ORACLY as if people will still use it **ten years from now**.

- Avoid trends in motion, copy, and layout fashion
- Prefer timeless craftsmanship — OR Lattice, held reveal, personal journal
- Prefer **depth of relationship** over **breadth of modalities**
- Prefer **honest emptiness** over **fake fullness**

Ask: *Would someone opening this screen in 2036 still feel the same sacred place?*

Whispers, not predictions. Questions, not answers.
