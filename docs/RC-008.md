**Status:** Canonical · Reading rhythm refinement

---

> *Reading is the longest interaction inside the application. Every paragraph should invite calm attention.*

Do **not** redesign. Do **not** add features. Only refine readability and craftsmanship.

---

## Mission

Improve how it feels to read — across reading screen, AI conversation, daily ritual, premium descriptions, and history.

The eye should move downward naturally. Nothing should feel visually dense.

---

## Typography stack

| Preset | Role | Notes |
|--------|------|-------|
| `ReadingTypography.display()` | DISPLAY — hero titles | Engraved tracking 2.0, gold/cream accent |
| `ReadingTypography.title()` | TITLE — feature titles | Cream, tracking 1.1 |
| `ReadingTypography.section()` / `sectionLabel()` | SECTION | Gold accent only, tracking 2.2 |
| `ReadingTypography.body()` / `bodyCore()` | BODY | Warm cream, line-height 1.76 / 1.82 |
| `ReadingTypography.secondary()` | SECONDARY | Muted warm grey, **not** italic |
| `ReadingTypography.micro()` | MICRO | Metadata / labels |
| `ReadingTypography.reflection()` / `opening()` / `closing()` | Short atmospheric italic only | Never giant blocks |
| `ReadingTypography.footnote()` | Short disclaimer whisper | Italic micro only |

Paragraph gap: `CraftsmanshipRhythm.paragraphGap`

**Color rule:** primary cream · secondary muted grey · gold accent only — never gold body paragraphs.

---

## Color readability

Secondary text contrast lifted without breaking dark atmosphere:

- `AppColors.textHint` → `#90889F`
- `AppColors.textMuted` → `#686076`
