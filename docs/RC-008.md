**Status:** Canonical · Reading rhythm refinement  
**Version:** 1.0

**Hierarchy:** [Master Directive](./MASTER_DIRECTIVE.md) → … → [RC-007 Craftsmanship](./RC-007.md) → **RC-008 Typography & Reading Comfort** → [RC-009 Intelligence Layer Foundation](./RC-009.md) → [AI Agent Guide](./AI_AGENT_GUIDE.md)

---

> *Reading is the longest interaction inside the application. Every paragraph should invite calm attention.*

Do **not** redesign. Do **not** add features. Only refine readability and craftsmanship.

---

## Mission

Improve how it feels to read — across reading screen, AI conversation, daily ritual, premium descriptions, and history.

The eye should move downward naturally. Nothing should feel visually dense.

---

## Typography stack

| Preset | Use | Source |
|--------|-----|--------|
| `ReadingTypography.body()` | Body paragraphs, chat bubbles | 1.76 line-height, 0.14 tracking |
| `ReadingTypography.bodyCore()` | Core interpretation text | 1.82 line-height |
| `ReadingTypography.reflection()` | Reflection questions, italic observations | 1.80 line-height |
| `ReadingTypography.sectionLabel()` | Section titles | Engraved tracking 2.2 |
| `ReadingTypography.cardTitle()` | Card / panel titles | 1.28 line-height |
| `ReadingTypography.footnote()` | Transparency, disclaimers | Muted italic body |
| `ReadingTypography.closing()` | Closing whispers | Reflection tone |

Paragraph gap: `CraftsmanshipRhythm.paragraphGap`

---

## Color readability

Secondary text contrast lifted without breaking dark atmosphere:

- `AppColors.textHint` → `#90889F`
- `AppColors.textMuted` → `#686076`
