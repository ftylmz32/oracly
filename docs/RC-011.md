# RC-011 — Experience Orchestrator

**Status:** Canonical · Central experience decision layer  
**Version:** 1.0  
**Scope:** Coordinate experience recommendations — no UI, no flow changes  
**Hierarchy:** [Master Directive](./MASTER_DIRECTIVE.md) → … → [RC-010 Reflection Engine](./RC-010.md) → **RC-011 Experience Orchestrator** → [RC-012 First-Time User Experience](./RC-012.md) → [AI Agent Guide](./AI_AGENT_GUIDE.md)

---

> *ORACLY gains a central brain that coordinates every future experience while keeping the architecture clean, predictable and scalable.*

Do **not** redesign. Do **not** modify navigation. Do **not** change current user flows.

---

## Mission

Create a single place that decides what kind of experience ORACLY presents — coordinating, never implementing UI.

Screens request an experience. The orchestrator returns a structured recommendation.

---

## Inputs

| Signal | Source |
|--------|--------|
| Reflection patterns | `ReflectionEngineService` |
| Journey history | Reading count via intelligence layer |
| Ritual completion | `DailyRitualService` |
| Time of day | `OraclyUniverseState` |
| Session duration | Optional parameter |
| User preferences | `SettingsService` |
| AI availability | Service config + feature flags |
| Feature flags | `ExperienceFeatureFlags` |

Future: Dream, Astrology, Numerology, Moon Rituals via `ExperienceSignalProvider`.

---

## Output models

| Model | Decides |
|-------|---------|
| `ExperienceContext` | Root recommendation |
| `GreetingContext` | Greeting tone and style key |
| `ReflectionContext` | Reflection style, insight surfacing |
| `JourneyContext` | Ritual highlight, journey memory |
| `RecommendationContext` | Highlights, premium relevance, flags |

---

## Architecture

```
ReflectionEngineService ──┐
DailyRitualService ───────┼──► ExperienceOrchestratorService
SettingsService ──────────┤           │
PremiumService ───────────┤           ▼
ExperienceSignalProvider ─┘    ExperienceOrchestrator
                                      │
                               GreetingDecider
                               ReflectionDecider
                               JourneyDecider
                               RecommendationDecider
                                      │
                                      ▼
                               ExperienceContext
```

**Rules:**
- UI never contains business decisions
- Orchestrator coordinates — deciders decide, screens render
- Extensible via `ExperienceSignalProvider` without modifying core
